# Glitch Frame

**A customizable glitch reveal animation script for Adobe After Effects.**

Glitch Frame is an Adobe After Effects script designed to create glitch-style reveal animations on selected layers. It simplifies the process of creating a glitch reveal effect by automating animation setup and allowing users to customize the effect through user-defined parameters.

Instead of manually building the effect from scratch, users can select a layer, configure their preferred settings, and generate a glitch reveal animation directly within After Effects.

## ✨ Features

- **Selected Layer Support** — Apply the glitch reveal animation to a selected layer in your composition.
- **Custom User Input** — Customize the animation using user-defined parameters.
- **Automated Animation Setup** — Generate the glitch reveal effect through a script rather than setting up every element manually.
- **Time-Saving Workflow** — Reduce repetitive steps when creating glitch-style reveals.
- **Adobe After Effects Integration** — Run the script directly inside After Effects.

## 🎬 How It Works

Glitch Frame follows a simple workflow:

1. Open your project in Adobe After Effects.
2. Select the layer you want to animate.
3. Run the Glitch Frame script.
4. Enter your desired settings through the available user inputs.
5. Let the script generate the glitch reveal animation on the selected layer.
6. Preview the result and make further adjustments to suit your composition.

*The available customization options depend on the current script implementation.*

## 🛠️ Requirements

- Adobe After Effects
- A composition containing the layer you want to animate
- The Glitch Frame script file

## 📦 Installation

1. Download or clone this repository.
2. Locate the Glitch Frame script file.
3. Open Adobe After Effects and load your project.
4. Select the target layer in the active composition.
5. Run the script using After Effects' scripting workflow.

For repeated use, you can place the script in the appropriate After Effects `Scripts` directory. Restart After Effects if necessary.

> **Note:** The exact installation steps may vary depending on the script format and your After Effects version.

## 🚀 Usage
